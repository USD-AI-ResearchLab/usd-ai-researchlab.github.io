# USD AI Research Lab Blog

## How to Write a Blog Post

### For Authors (All @usd.edu members)

1. **Fork this repository** on GitHub
2. **Create a new markdown file** in `content/blog/` folder
   - Name format: `YYYY-MM-DD-your-post-title.md` (e.g., `2026-03-10-intro-to-transformers.md`)
3. **Add frontmatter** at the top of your file (see template below)
4. **Write your content** in Markdown
5. **Submit a Pull Request** to the main repository
6. **Wait for review** from one of the reviewers

### Blog Post Template

Create a new `.md` file with this structure:

```yaml
---
title: "Your Blog Post Title"
author: "Your Name"
email: "your.email@usd.edu"
date: "2026-03-10"
tags: ["AI", "Machine Learning", "Research"]
excerpt: "A brief description of your post (1-2 sentences)"
image: "/images/blog/your-image.jpg"
---
```

Then write your content below the frontmatter using Markdown.

### Review Process

1. Author submits PR with new blog post
2. Reviewer reviews the content
3. Reviewer can:
   - **Approve** - Post gets published
   - **Request changes** - Author updates the post
   - **Comment** - Discussion on the post
4. Once approved and merged, the post appears on the blog!

## Markdown Features Supported

- **Bold**, *italic*, ~~strikethrough~~
- Headers (# H1, ## H2, ### H3)
- Lists (ordered and unordered)
- Code blocks with syntax highlighting
- Tables
- Images and Links
- Block quotes
- LaTeX math equations
